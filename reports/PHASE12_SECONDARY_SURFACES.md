# Phase 12 — Settings, dialogs и ContextMenu

Выполнена только Phase 12. Текущее состояние checkout использовано как источник истины; существующие изменения других фаз, native backend и iOS не сбрасывались.

1. **Settings architecture.** AppSettings использует единый native Dialog. Сохранён desktop size cap 920×660 px с ограничением по viewport, sidebar 180 px и отдельным content scroll. Все четыре раздела сохраняют одинаковый bounding box; sections остаются mounted/hidden, updater и PhoneSync не пересоздаются при переключении. Navigation — обычные named buttons с aria-current, Up/Down/Home/End, спокойным selected state и tokens. Giant nested cards/blur/gradient/glow удалены. Аудит показал: final referenceIdentity cascade уже фиксировал размер Settings; проблема была в многочисленных конфликтующих owners и разных dialog implementations.
2. **Sections.** Общие: прежние PhoneSync и signed updater, QR 160 px слева, status/address/explanation/actions справа, disconnect — destructive secondary. Внешний вид: реальные palette/custom RGB/HEX и TrackDisplay preferences; Button/Input миграция, named checkbox/color controls, без новых fake theme/density/motion settings. Плеер: актуальный preview, reset и объяснение ручного resize. Библиотека: реальные folders/status/path, управление через прежний native picker/scan/remove flow, существующая папка удалённых песен. Добавление/сканирование/transfer/updater backend не изменены.
3. **Player customization.** Preview показывает identity/favorite/context как закреплённую presentation, пять draggable transport controls, Queue/Lyrics и закреплённые menu/volume glyphs. Поддерживаемые draggable IDs: shuffle, previous, play, next, repeat, queue, lyrics. Trash/Visualizer/Lock/Metadata/Autoplay/format не предлагаются как permanent draggable controls. Сохранены order.v3, positions.v3, locked.v2, исходная geometry/drag architecture и merge остальных positions. Старые retired positions сохраняются при drag; keys удаляются только по явному existing reset. Drop position видна по движению и outline; invalid drop становится danger outline и не сохраняет preference. «Сбросить расположение» использует существующий reset. Preview использует canonical IconButton/Tooltip и accessible groups.
4. **Dialog shell.** Единственный generic Dialog.tsx с small/medium/large: 440/560/800 px, max viewport bounds, surface-secondary, system radius/border/popover shadow, dark dim без blur. Общие header/title/description associations/close/content/footer; aria-modal, native inert/showModal, явный Tab wrap, Escape, focus origin/return, busy close guard. Backdrop dismissal требует pointer start outside dialog, поэтому drag из content не закрывает окно. initialFocus применяется после showModal: PlaylistEditor начинает на Name, confirmations — на Cancel. ListeningDialog проверен: его единственный consumer — специальный fullscreen Now Playing; он сохранён, generic surfaces больше от него не зависят.
5. **Мигрированные dialogs.** AppSettings; PlaylistEditor create/edit/queue-save; MusicFoldersDialog (из App); TrackMetadataDialog; MoveTrackDialog через ConfirmationDialog; playlist delete confirmation; Queue clear confirmation; существующий ActionDialog для track/list ordering actions. Generic native dialog markup теперь находится только в Dialog; ListeningDialog отдельно обслуживает fullscreen. Playlist Enter submit/Cancel/Escape и inline empty-name/server feedback работают без изменения collection action payloads или partial create/add retry behavior. Music folders используют существующие callbacks; add/rescan actions закреплены в shell footer. Metadata — компактный readonly DL с secondary technical/path disclosure, без fake inputs и пустых неизвестных technical rows. Destructive confirmations имеют Cancel и canonical destructive button; queue/playlist/file operations не переписаны.
6. **ContextMenu geometry/style.** Сохранён один ContextMenu для track/entity/playlist/player. Единственный owner — TrackContextMenu.css: content-based width, min 196/max 320 px, solid near-black surface-panel, subtle border, popover shadow, outer radius 8 px, inner hover radius 4 px из существующих tokens. Icons/typography спокойные, labels 11 px с меньшим tracking, rows normal weight, whole-row hover/focus/press. Только destructive items используют danger; disabled остаются читаемыми и не действуют. Separator только для explicit separated group. Player menu оставляет rare actions: metadata/autoplay/visualizer, layout lock и отдельную destructive trash group.

   **Отклонение от цели 15–20%:** фактический старый referenceIdentity уже задавал rows min-height 30 px. Новый обязательный target — 40 px. При сравнении тех же Track actions с pre-phase CSS baseline измерены примерно 208×419 против 214×535 px (ширина × intrinsic height). Поэтому общая геометрия не уменьшена на 15–20%; сохранение этого процента противоречило бы требованию нормальных hit areas. Padding/radius/surface унифицированы, высота увеличена ради доступности. Эта разница отмечена явно, без заявления о выполненном процентном уплотнении.
7. **Submenu/keyboard.** Root menus поддерживают Up/Down/Home/End и пропускают disabled items. Right открывает playlist submenu и ставит focus на его item; Left возвращает summary. Escape сначала закрывает submenu, затем root menu, затем родительский dialog/fullscreen. Pointer переход на submenu не закрывает слой. Existing placeContextMenu/placeSubmenu не изменены; flip у правого/нижнего края проверен, arrow отражает left placement. Delete показывается только для существующего queue remove action и вызывает тот же callback из открытого root menu; других выдуманных shortcuts нет. Track selection/playlist/entity action semantics сохранены.
8. **Focus/layering.** ContextMenu портируется в ближайший focused open dialog; fallback fullscreen/body сохранён. Любой modal использует полный client viewport вместо safe bottom скрытого lower Player. Tooltip сохраняет Phase 10 nearest-dialog portal. Проверены generic dialog menu и fullscreen menu layering/Escape. Menu-origin позволяет dialog, открытый через menu, вернуть focus на настоящий opener. Cleanup не крадёт focus у новой навигации: воспроизведён Ctrl+K regression при unconditional menu focus return, исправлен guard, focused Search input остаётся активным. Search business logic не менялась.
9. **Legacy cleanup.** Presentation owners: Dialog.css — shell/forms/folders/confirmation content; SettingsPresentation.css — Settings/PhoneSync/preview; TrackMetadataDialog.css — только readonly content; TrackContextMenu.css — menu/submenu. Из mixed legacy owners удалены 399 заменённых/неиспользуемых selectors/rules, включая старые dialog/settings/menu/danger/scan styles; unrelated selector lists сохранены. settingsPolish.css и phoneSync.css удалены вместе с imports. Новых !important и global override sheet нет. Main presentation CSS (DesktopHome/SearchPage/QueuePage/PlayerPresentation/NowPlayingPanel), designTokens и fullscreen JSX сверены с начальным snapshot: unchanged. Playback engine region player.tsx byte-equivalent; изменена только rare-menu grouping/presentation. Native/model contracts не менялись.
10. **Короткий QA.** scripts/phase12-secondary-qa.cjs: real App + Chrome + synthetic Tauri IPC. Passed: все Settings sections без resize jump; navigation/focus trap/return; preview семь IDs, valid/invalid drag, сохранение retired positions/reset; Create Playlist initial focus, empty validation, Enter submit; nested folders add/remove/return; metadata/technical/path; destructive Cancel; Track/Entity/Playlist/Player menus; submenu keyboard/mouse/selection/flip; real queue Delete action; fullscreen layering; generic-dialog menu portal test; Ctrl+K focus integration. Settings и small/medium/large dialogs проверены на 1280×720, 1920×1080, 2560×1440: bounds/overflow корректны. Frontend **158/158**, regression **PASS**, production build **PASS**, git diff --check **PASS**. Evidence/screenshots — qa-output/phase12-secondary, baseline — qa-output/phase12-before.

    Runtime evidence ограничено browser/fixture и небольшим real-component portal host для generic dialog. Реальный updater install/restart, PhoneSync pairing/transfer, native picker/scanner/file moves, физическое audio и установленный Tauri/WebView executable не запускались. Destructive QA отменяет реальные confirmation callbacks; folder/playlist mutations выполняются только synthetic IPC fixture. Exhaustive QA прежних фаз и Rust matrix не запускались.
11. **Оставлено следующим фазам.** Global toast/snackbar/Undo, global drag/drop, metadata editing, volume persistence, audio device picker, окончательное решение о Player height/resize, production/hardware/network QA. Эти системы не добавлялись. Установленный executable не заменялся. К следующей фазе не переходили.

## Архитектура и взаимодействие

| Before | After |
| --- | --- |
| Несколько native dialog shells с разными headers/actions/modality handlers | Dialog.tsx + three size variants + ConfirmationDialog wrapper |
| Разные surfaces, backdrop blur, glass/glow, giant min-height/card rules | Один Dialog.css с tokens, dark dim, bounded content scroll и fixed footer |
| Settings уже были fixed-size в final cascade, но имели несколько owners | Один SettingsPresentation.css, тот же 920×660 cap, compact nav/content sections |
| AppSettings native buttons/RGB input и card-in-card presentation | Canonical Button/Input; semantic sections, named navigation and fields |
| PhoneSync и updater presentation отдельными card/legacy rules | QR/status two-column section, destructive disconnect, compact unchanged updater flow |
| Player preview показывал retired permanent controls | Семь draggable IDs, actual Phase 11 zones, fixed actions, canonical tooltips/accessible groups |
| Нет явного invalid-drop feedback в Settings preview | Shared strip data-drop-valid + visible valid/danger outline; invalid drop preserves storage |
| PlaylistEditor сам открывал dialog, initial autofocus терялся при showModal | Общий shell, explicit post-open Name focus, Cancel и fixed footer, inline validation/Enter submit |
| Music folders dialog встроен в App с собственным shell | MusicFoldersDialog, прежние callbacks/status, fixed add/rescan footer и компактные rows |
| Metadata inspector со своим header/footer/surface и unknown technical rows | Общий large shell, readonly primary DL и nonempty technical/path disclosure |
| Move/playlist-delete/queue-clear confirmation оформлялись неодинаково | Единый Cancel/Confirm pattern, safe Cancel focus и destructive CTA |
| ActionDialog имел собственный native modal markup/buttons | Общий medium shell и canonical actions/select styling; исходные payloads |
| Menu styles распределены по legacy sheets, 30 px rows в final cascade | Единый token owner, 40 px rows, lighter surface/type/icons, readable disabled states |
| Submenu не имел Right/Left focus navigation | Arrow navigation, expanded semantics, child-first Escape и existing positioning/flip |
| Body/fullscreen-only portal assumptions | Nearest open generic dialog/fullscreen portal, сохранён Tooltip contract |
| Menu teardown мог возвращать focus поверх новой Search navigation | Focus return только когда focus был потерян вместе с закрытым menu |
| Queue Delete shortcut существовал только в list, не был представлен в menu | Named shortcut для этого action и тот же callback при Delete в root menu |
| Rare Player trash был в общей группе и без destructive MenuItem | Layout отдельно, destructive trash group, остальные rare actions остаются в menu |
| Старые assertions ссылались на самостоятельные shells/style owners | Assertions отражают общий Dialog/ContextMenu owners; текущие regression tests сохранены |
| Нет Phase 12 acceptance evidence | Focused runtime script, snapshots, geometry/density metrics и этот отчёт |

Основные created/changed components: Dialog/ConfirmationDialog, AppSettings, PhoneSync, PlayerLayoutPreview, MusicFoldersDialog, PlaylistEditor/ActionDialog, MoveTrackDialog, TrackMetadataDialog, Queue confirmation, ContextMenu/MenuItem/PlaylistSubmenu, PlayerControlStrip feedback, Player rare-menu composition. Backend actions, playback/queue/lyrics models и основные страницы не переделаны.
