# Phase 10 — полноэкранный Now Playing

Выполнена только Phase 10. Проверки относятся к текущему checkout; существующие изменения предыдущих фаз, native backend и iOS не сбрасывались. Установленный Windows executable не заменялся.

1. **Исходная архитектура.** `App` открывал единственный `ListeningDialog` с `NowPlayingPanel`: floating native modal до 900 px, ограниченная высота, собственные невиртуализированные queue buttons, compact LyricsView, минимальный transport. Аудит подтвердил, что других consumers ListeningDialog нет.
2. **Новый экран.** Тот же ListeningDialog через `showModal()` занимает всю client area: без card, внешних полей и backdrop-click dismissal. NowPlayingPanel заменён на месте. AppShell, Sidebar, MainContent, PlayerArea и usePlayer остаются mounted. Native titlebar находится за пределами DOM и не изменялся.
3. **Layering и focus.** Native top layer делает underlying document inert и блокирует pointer/focus. Дополнительный Tab wrap держит traversal внутри экранных controls. Close имеет autofocus и accessible name; X/Escape возвращают focus на исходный opener. ContextMenu портируется внутрь открытого overlay, поэтому остаётся поверх экрана; Escape сначала закрывает menu. Tooltip и TrackList drag ghost используют ближайший открытый dialog. Metadata dialog использует существующий native modal flow поверх Now Playing.
4. **Desktop layout.** Две колонки 45/55 с ограниченной шириной 2000 px, спокойным separator и постоянной геометрией. Левая часть центрирует artwork, информацию и transport; правая занимает доступную высоту. Ни tab, ни смена трека не сдвигают primary column. При ширине менее 1000 px композиция компактнее, менее 700 px — stacked; volume остаётся доступен.
5. **Artwork.** Прежний Cover/convertFileSrc/onError pipeline. Проверенные размеры 360 px на 1280×720, 480 px на 1920×1080, 520 px на 2560×1440. Нет анализа картинки, фонового cover, tint или blur. Для длинного title две строки с wrapping/clamp и полным text/title; artist/album truncate независимо.
6. **Playback controls.** Shuffle, Previous, primary Play/Pause, Next, Repeat вызывают исходный player. Active modes доступны через aria-pressed; repeat track имеет badge. Seek использует такой же draft/commit, как нижний player: drag/click commit на PointerUp, keyboard commit на KeyUp, step 0.1; cancel/blur сбрасывают draft. Hover даёт time preview, elapsed/total используют tabular numbers. Единственный volume range вызывает changeVolume; локальные draft seek/volume — только presentation, не второй controller. Space работает на неинтерактивном focus и не перехватывает button/range/tab/queue/lyrics controls; Left/Right глобально не переопределяются. Playback engine/media integration не изменены.
7. **LyricsView.** Прямой canonical LyricsView с showHeader=false, исходными track/document/loading/status/error/retry/position/onSeek и controlled follow. Lookup/error UI не продублирован. В fullscreen synced font 18–24 px. Найден воспроизводимый resize regression: observer менял center padding, но не пересчитывал active scroll. Минимальное исправление добавляет geometry dependency к существующему follow effect; manual follow=false продолжает подавлять scroll. Исправление проверено на resize, manual pause/return и reduced motion.
8. **Queue.** Canonical TrackList над upcoming slice того же Phase 7 queue. Current исключён, occurrence keys сохранены; jump/remove/Delete/multi-remove/context/reorder используют player callbacks и абсолютный offset. Список виртуализирован прежним TrackList. Drag ghost теперь виден в native top layer. «Открыть очередь» закрывает overlay и вызывает обычную navigation; empty state — «Дальше ничего нет». Второй QueuePage/model не создан.
9. **About.** Компактный definition list с фактически доступными album/artist/year/genre/format/duration. Отсутствующие поля пропущены. Technical section показывается только при наличии size_bytes; codec/bitrate/sample rate/bit depth/channels отсутствуют в текущем Track contract и не выдуманы. Полный путь/metadata остаются в TrackMetadataDialog.
10. **Resize/motion.** Экран не пересоздаётся при live resize или track transition, выбранный tab сохраняется. На 1280×720 видны artwork, transport, seek, volume и right content; horizontal overflow отсутствует. Enter — спокойный fade 180 ms, reduced motion отключает его; закрытие немедленное. Параллакса, zoom и фоновых эффектов нет.
11. **Legacy cleanup.** Удалены 105 старых selectors details-panel/listening-dialog/listening-controls/now-playing-tabs/now-panel-body/panel-queue/panel-about/panel-lyrics из styles, glassRedesign, desktopLayout, mobileIdentity, referenceIdentity, uiPolish, listeningExperience, LyricsPresentation. Дополнительно удалены два details-resize selectors и неиспользуемый detailsLayoutClass из App/model. Единственный presentation owner — NowPlayingPanel.css; shared Lyrics presentation остаётся в LyricsPresentation.css. !important не добавлен. Obsolete source assertions и embedded selector в Phase 9 QA адаптированы к новой архитектуре; Phase 9 exhaustive QA не запускался.
12. **Короткий QA.** `scripts/phase10-now-playing-qa.cjs` использует реальный App в Chrome с synthetic Tauri IPC. Passed: open/X/Escape/focus return/Tab wrap/background inert, normal/long title, synced active/manual/follow/seek/resize, plain/no lyrics, upcoming/jump/Delete/reorder/ghost, empty queue/navigation, About/technical/native metadata, Previous/Next/natural transition со стабильной DOM identity/tab, controls/seek/volume/Space, menu/tooltip layering, reduced motion. Три viewport: 1280×720, 1920×1080, 2560×1440; controls в viewport, overflow=false, active line center delta <1 px. Frontend: **158/158**; regression scripts: **PASS**; production build: **PASS**; git diff --check: **PASS**. Evidence/screenshots — qa-output/phase10-now-playing. Это browser/fixture evidence, не доказательство работы физического audio device, hardware media keys или установленного Tauri/WebView executable. Native код не менялся, Rust matrix и exhaustive прошлых фаз не запускались.
13. **Оставлено Phase 11/12.** ContextMenu visual redesign, generic dialogs, toast system, global drag/drop, полный redesign нижнего player/Settings и финальная production QA. К Phase 11 не переходили.

## Архитектура и взаимодействие

| Before | After |
| --- | --- |
| NowPlayingPanel: маленький modal с собственной композиционной веткой | Единственный полноразмерный screen; две устойчивые колонки и адаптивный artwork |
| ListeningDialog: card/backdrop dismissal, native Tab мог уходить в browser chrome | Full client-area native modal, без background dismissal, явный Tab wrap и возврат focus |
| App: obsolete detailsLayoutClass(false); lyrics tab исключался при открытой background Lyrics page | Удалена obsolete branch/helper; background inert, все три tabs доступны; wired like/context/queue navigation |
| ContextMenu: body portal и safe bottom нижнего player | Portal внутрь overlay и полная client-area height; прежние actions/styles |
| Tooltip/TrackList drag ghost: body portal за native top layer | Portal в ближайший open dialog, прежние компоненты и поведение |
| Минимальный transport и immediate seek onChange маленького panel | Полные controls, mode states, draft/commit seek как в Player, hover time preview, один volume |
| Compact Lyrics font и resize без recenter | Прямой showHeader=false LyricsView, адаптивный font, geometry-based recenter только при follow |
| Queue: собственные buttons, без remove/reorder/virtualization | Canonical TrackList с occurrence keys, jump/remove/context/reorder и переходом в Queue |
| About: однотипная вертикальная metadata presentation | Compact definition list, непустая technical disclosure и существующий full metadata flow |
| Старые Now Playing selectors в восьми style owners + dead splitter selectors/helper | Scoped NowPlayingPanel.css; legacy selectors/helper удалены, unrelated selector lists сохранены |
| Source assertions и старый embed QA selector требовали compact panel | Assertions/selector отражают canonical fullscreen architecture; новый focused runtime QA и этот отчёт |

Изменённые reusable components: ListeningDialog, ContextMenu (portal/safe bounds), Tooltip (portal), TrackList (ghost portal), LyricsView (подтверждённый resize regression). Новый reusable playback/lyrics/queue renderer не создавался. Основные presentation изменения: NowPlayingPanel.tsx и новый NowPlayingPanel.css; integration — App.tsx.
