# Undertone iOS 0.5 — adaptation of the personal-player specification

User decision: personal local player; social/account features excluded. Source document: C:/Users/nikita/Downloads/spotify_mobile_music_only_spec_2026-10-02.md. Full coverage and remaining requirements: [feature matrix](../docs/mobile/01-feature-matrix.md).

## Changes

| Before | After |
| --- | --- |
| Library primarily browsed downloaded/PC tracks | Home/Search/Library/optional Create, entity filters and separate library search |
| No phone-only library organization | Personal playlists, nested folders, pins, saved albums/artists and local favorites |
| PC playlists supported limited edits | Track order/description edits with durable operations, idempotence and stale-baseline conflict rejection; local cover image import |
| Queue lost on relaunch | Queue/track/position/repeat checkpointed and restored paused; history records actual playback |
| Manual single-copy management | Selection/download/favorite/add-to-playlist/remove phone copies, latest removal undo and explicit trash cleanup |
| No original export or object codes | System sharing of real original files and private Undertone links/QR without connection credentials |
| No text/video pages | Real PC lyrics and LRC/TXT import/cache, timed highlighting/seek; user-provided looped visual/video |
| Few preferences | Create visibility, lyrics preview, visual toggle, explicit offline mode, original-quality label and bounded system-decoder crossfade |
| Hidden tracks unsupported | Durable hide/unhide with original/desktop alias matching, automatic queue skips, dimmed local rows, global reset |
| Context-menu-only queue additions | Leading song swipe to play next; queue multi-select removal |
| Older browser counterpart | Updated demonstration shell/entities/creation/search/actions/settings, local demo persistence and native-source change indicator |

Original audio bytes are preserved. Crossfade changes playback volumes only; Vorbis has no overlap. Video uses user-provided files and assumes their timeline matches the audio. Lyrics use actual text from the PC database or import, never generated lyrics.

PC-origin favorites/playlists synchronize. Phone-created personal playlists, folders, pins, bookmarks, covers, history, visuals, hidden flags and preferences are device-local. Original-file deletion on phone never deletes PC files. Undo restores only the latest removal in the current app session; trash remains separately visible after restart.

## Delivery and limits

Update the PC companion executable for new lyrics and playlist-order endpoints. Update the IPA through the already working iLoader path with the same account and bundle identity local.undertone.ios; do not uninstall. Signing/update preservation remains a device test.

This delivery does not implement every non-social requirement. Gapless/normalization/Automix, WidgetKit, full cover composition, selected-line lyrics share cards/translation, unified entity grid, playlist deletion undo and landscape/video correspondence remain recorded in the feature matrix. Same-LAN PC connectivity and unsupported Ogg Opus remain existing boundaries. Advanced physical-device checks are deferred at the user's request in IOS_DEVICE_CHECKS_LATER.md.
