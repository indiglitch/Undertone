# Undertone iOS 0.3

## Changes

- Native List reuse, isolated PlaybackClock, async catalog decode/index/search, 180 ms search debounce, cached album grouping and O(1) installed/favorite identity sets. Heavy file hashing/metadata and cover decode run outside the main actor.
- Persistent background URLSession queue, two concurrent transfers, pause/resume checkpoints, restart recovery, pinned TLS, size/SHA-256 verification and background event completion after install. PC supports HTTP Range and ETag/If-Range.
- Bidirectional favorites/playlists: stable sync identities, durable offline operation queue, idempotent batch application in SQLite transactions, desktop change event and foreground refresh. Conflicts retain pending edits; a Synchronization screen allows individual cancellation.
- Bonjour discovery of the paired fingerprint, strict certificate pinning and LAN-interface-only Windows advertising. A real test initially exposed VPN-address contamination; the final discovery smoke passed with the LAN address.
- Embedded/imported/PC artwork, persistent thumbnails, bounded decoded-image cache, at most three cover fetches. Authenticated artwork endpoint resolves only registered track identities.
- Streaming Ogg Vorbis decoder (stb_vorbis 1.22, pinned upstream source and MIT/public-domain license), bounded PCM buffers, seek; native FLAC verified. No transcoding or original tag rewriting.
- Shared original bytes retain multiple PC identities so playlist references do not disappear. Manifest stays compatible with 0.1/0.2.

| Before | After |
|---|---|
| Playback position invalidated the whole library every 0.5 s | Only the playback clock/slider observes position |
| Long scroll content and repeated grouping/filtering | Native reused rows and off-main cached indexes |
| Downloads required the foreground | Persistent system background transfers and resume data |
| PC playlists/favorites/artwork unavailable on phone | Bidirectional collections and cached covers |

## Device acceptance still required

Actual iPhone scrolling/FPS, background transfer scheduling during screen lock, recovery after force quit/reboot, IPA update/weekly signing preservation and physical audio interruptions need device testing. The simulator is not the user's iOS 27.0.1 phone. Keep the same signing account and bundle ID, and update without uninstalling to preserve the application container. Background transfer needs a running PC on the same reachable Wi-Fi; iOS controls scheduling and force quitting cancels system transfers until reopen. Ogg Vorbis is supported by the added decoder; Ogg Opus is not covered.
