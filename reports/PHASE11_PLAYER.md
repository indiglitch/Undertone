# Phase 11 — постоянный Player

Выполнена только Phase 11. Текущее состояние checkout использовано как источник истины; существующие изменения предыдущих фаз/native/iOS не сбрасывались. Установленный executable не заменялся.

1. **Старая архитектура.** Единственный usePlayer в App, но Player presentation задавали playerResponsive/playerControlLayout/playerFreeLayout/playerPolish, desktopLayout, styles, uiPolish, glassRedesign, mobileIdentity и referenceIdentity. Были противоречивые grid/contents/flex layouts, free-position strips, targets 31–38 px, отдельные desktop/narrow DOM branches, mini visualizer meter, format span, trash/lock рядом с identity. Output/device selector в действительности отсутствует: player-output — контейнер utilities, native audio использует default output. Volume/seek уже имели собственные UI drafts; fullscreen повторял seek implementation.
2. **Новая структура.** LEFT: 44 px Cover, title/artist с ellipsis/full title, Favorite и существующий TrackContextMenu. CENTER: Shuffle/Previous/primary Play/Next/Repeat и elapsed/seek/total. RIGHT: Queue/Lyrics, меню плеера, единственный mute/volume slider/readout. Track identity открывает прежний fullscreen Now Playing; отдельная Now Playing button не добавлена. Тёмный ровный background, тонкая верхняя граница; нет gradient/glass/glow/rounded footer. Canonical Button/IconButton/Tooltip, targets минимум 40 px, primary Play 48 px, явные aria-pressed и violet active states.
3. **Сохранённые/перенесённые controls.** Все пять transport controls, Favorite, Queue, Lyrics, volume/mute и track context остаются. Metadata, Autoplay, полноценный Visualizer, Trash и layout Lock находятся в existing ContextMenu плеера; их callbacks сохранены. Удалены из постоянной композиции mini visualizer meter, format span, отдельные trash/lock buttons; output selector не выдуман. Queue открывает management page, Lyrics — существующую dedicated Lyrics view, fullscreen Далее остаётся preview. Queue/Lyrics active states соответствуют navigation.
4. **Высота.** Canonical shell token остаётся 104 px; текущая полная reservation — 116 px вместе с 12 px нижнего padding. Не уменьшена: 48 px transport + 40 px seek hit area + вертикальные отступы требуют текущего minimum. Новых height overrides/token forks нет. MainContent заканчивается над Player. Ручной resize и double-click reset сохранены и проверены, включая увеличенную высоту.
5. **Seek/volume.** Новый маленький usePlayerSeek — UI-only draft/commit helper для Player и прежнего NowPlayingPanel; никакого playback controller. Pointer drag не вызывает IPC до release, keyboard commit — Arrow/Home/End/Page keys; cancel/blur не отправляют command, повторный PointerUp не создаёт duplicate commit, track change сбрасывает draft. Оба range используют прежние player.command seek semantics. Volume сохраняет immediate readout, slider/keyboard, 1% wheel, mute/restore last nonzero value. При изменении volume через fullscreen remembered mute value также обновляется. Volume остаётся доступен при уменьшении width.
6. **Fullscreen sync.** Воспроизведён реальный баг: successful changeVolume обновлял только statusRef, React status оставался 0.65 вместо 0.37 до poll. Единственное изменение usePlayer engine — serial-guarded update одного status.volume после ACK; остальные поля/queue/playback logic не изменены. Regression test теперь проходит без poll. Общие status/modes/collections немедленно отражают play, progress, volume, shuffle/repeat, track и favorite в обоих surfaces. Fullscreen CSS и композиция не менялись; в NowPlayingPanel заменён только дублированный seek behavior на helper.
7. **Responsive.** Проверены live 1280×720, 1920×1080, 2560×1440, long title/artist и custom positions. Horizontal overflow отсутствует, identity/Play/volume доступны, targets в viewport и >=40 px. При меньшей ширине utilities и volume получают две устойчивые строки внутри right zone, сокращаются gaps и volume percentage; transport не превращается в смешанную strip всех controls. No track — neutral state, не скрытый footer. Play остаётся доступен для existing random-library start, если library playable; empty library disables it. Known missing current file показывает «Файл недоступен» и блокирует Play/seek/Space; loaded playing audio можно поставить на паузу. Использован прежний trackAvailability cache/IPC, без новой global error model.
8. **Custom layout compatibility.** PlayerControlStrip и playerControlLayout model сохранены byte-identical. Drag/pointer capture/threshold/Escape/cancel/click suppression/ResizeObserver остаются. Поддерживаемая постоянная customization: пять transport controls и Queue/Lyrics внутри своих zones. Existing order.v3/positions.v3/locked.v2 keys, normalization и merge preferences сохранены; остальные IDs/positions не удалены из storage. Favorite/volume закреплены для стабильности; Trash/Autoplay/Visualizer/Lock теперь menu actions, их старые positions не применяются к постоянному Player. Settings UI/PlayerLayoutPreview.tsx не переписывался: пока показывает старый полный набор. Обновление preview под поддерживаемый набор оставлено Phase 12; это ограничение текущей compatibility, не обещание полного старого free-layout поведения.
9. **CSS cleanup.** Единственный permanent presentation owner — PlayerPresentation.css. Shared functional strip geometry — playerControlLayout.css; explicit Settings preview rules сохранены. Удалены 202 заменённых permanent-player selectors из mixed legacy sheets с сохранением unrelated selector lists. playerPolish.css, playerFreeLayout.css, playerResponsive.css удалены, их imports убраны; функциональная absolute canvas/scroll/drag geometry перенесена в shared strip owner. Shell/PlayerArea/resize contracts, design tokens и fullscreen CSS сохранены. Новых !important нет.
10. **Короткий QA.** scripts/phase11-player-qa.cjs запускает реальный App в Chrome с synthetic Tauri IPC. Passed: no track, known missing file, Play/Pause/Prev/Next, Shuffle/Repeat pressed states, seek draft/one-shot commit/keyboard, volume slider/keyboard/wheel/mute, Favorite, Queue/Lyrics/Now Playing navigation, long title/artist, natural transition, 3 live viewports, custom drag/persistence, resize/reset, context menu/focus return и Space guard. Проверена двусторонняя fullscreen synchronization volume/shuffle/progress и общие favorite/repeat states. Frontend **158/158**, regression **PASS** (включая новый volume ACK и shared seek cancellation tests), production build **PASS**, git diff --check **PASS**. Evidence: qa-output/phase11-player/results.json и screenshots. Это browser/synthetic IPC evidence; физический audio device, hardware media keys и установленный Tauri/WebView executable не проверены. Exhaustive QA предыдущих фаз и Rust matrix не запускались: native код не менялся.
11. **Phase 12/14.** Обновить Settings preview/customization copy под поддерживаемые groups; решить судьбу свободной высоты Player (сейчас сохранена); определить volume persistence при native restart. Текущий native AudioStatus инициализирует volume=0.65, PlaybackSession не хранит volume; navigation/overlay volume сохраняют, межзапусковая persistence пока отсутствует и не добавлялась как новая engine feature. Output/device picker не реализован. Generic dialogs, ContextMenu visual redesign, Settings UI, toast/global drag и финальная production/hardware QA оставлены следующим фазам. К следующей фазе не переходили.

## Композиция и доступность

| Before | After |
| --- | --- |
| player.tsx: три movable strips и narrow branch со всеми controls/дублированием utilities | Один стабильный LEFT/CENTER/RIGHT DOM; identity + transport + utilities |
| Слабая title hierarchy и неявный opener | 44 px Cover, title/artist ellipsis/full title, named identity opener |
| Trash/Lock/meter/format занимали постоянное место | Rare actions в существующем ContextMenu; meter/format убраны из footer |
| Native icon-button markup, маленькие targets и неявные modes | Canonical primitives, 40 px minimum, 48 px primary, aria-pressed и видимые active indicators |
| Queue не имела active state | App передаёт queueOpen; Lyrics и Queue отражают navigation |
| Missing current file выглядел playable | Existing availability check, readable state и disabled Play/seek/Space |
| Shared player status.volume обновлялся только poll | ACK обновляет только общее volume с прежней serial guard |
| Mute remembered значение не учитывало volume из fullscreen | Last positive shared volume обновляет remembered value |
| Две копии seek drafts в mini/fullscreen | usePlayerSeek UI helper: preview, one commit, cancellation, track reset |
| Нет scope-aware глобального Space handler | Space toggle вне интерактивных targets; dialogs/menu/lyrics/inputs не перехватываются |
| Player context menu не возвращал focus на icon opener | App запоминает opener, Escape возвращает focus |
| CSS presentation в десяти пересекающихся слоях | PlayerPresentation.css; 202 legacy selectors и три sheets удалены |
| Functional strip geometry зависела от playerFreeLayout overrides | Shared playerControlLayout.css с absolute canvas/scroll и 40 px items |
| Historical source assertions требовали старые markup/stylesheet/meter | Assertions отражают финальную архитектуру; прежние model tests сохранены |
| Volume ACK/shared seek не имели regression coverage | scripts/player-regression.mjs проверяет ACK без poll и single/cancelled commits |
| Не было focused Phase 11 evidence | Новый browser QA и этот отчёт с границами проверки |

Основные изменённые/созданные файлы: src/player.tsx, src/PlayerPresentation.css, src/usePlayerSeek.ts, src/NowPlayingPanel.tsx (helper integration), src/App.tsx, src/playerControlLayout.css, src/main.tsx, legacy style owners, относящиеся к Player frontend assertions, scripts/player-regression.mjs, scripts/phase11-player-qa.cjs. LyricsView.tsx, QueuePage.tsx, PlayerLayoutPreview.tsx, playerControlLayout.ts, PlayerControlStrip.tsx, designTokens.css и NowPlayingPanel.css сверены с начальным snapshot: byte-identical.
