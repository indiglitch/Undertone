# Undertone iOS 0.6.0 — unified interface and shared playlists

Source commit: 8244f6b. Successful CI: https://github.com/indiglitch/Undertone/actions/runs/36959241005

| Before | After |
| --- | --- |
| Home tracks lacked the common menu | One reusable track row/menu across Home, Search, collections, queue and player |
| Downloaded and PC tracks were separated | One sorted list with availability and download progress |
| Remote playback required explicit download | Tap resolves, downloads/verifies the original, then plays; queue advancement uses the same resolver |
| Current track was difficult to distinguish | Accent title, background and playing/paused icon based on all track identities |
| Search duplicated Done | One prominent keyboard toolbar button, with a small bottom gap |
| Albums/playlists had inconsistent actions | Reusable collection menus with play/shuffle/download and applicable edit/save actions |
| Local playlists/folders formed a separate library | Shared PC/iPhone playlists with persisted offline operations; folders removed |
| Playback errors interrupted the interface | Brief dismissible popup, automatically hidden after four seconds |
| Home lacked direct synchronization | Sync button refreshes the paired PC or opens pairing |

## Boundaries

Physical iPhone installation, original downloads over the user's Wi-Fi and cross-device playlist convergence have not been retested for 0.6.0. The prior deferred device checklist remains pending. Browser playback/downloads are demonstrations, not evidence of native audio/network success.

Phone-imported originals without a known PC identity remain visible in shared playlists with persisted pending operations. They synchronize once the same original has a PC catalog identity; uploading phone originals to the PC is not implemented. Local playlist data is retired only after the shared migration state is saved. Offline edits to unresolved tracks do not block operations on other playlists.

Install over the existing app using the same signing account and bundle identity; do not uninstall to update.
