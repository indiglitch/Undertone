Исправлены подтверждённые ошибки из PROJECT_CHECKUP_2026-09-30.md и UI_CHECKUP_2026-09-30.md. Изменения доступны в исходниках и запущенной dev-версии. Установщик и релиз не публиковались.

## Поведение приложения

| До | После |
|---|---|
| Опрос пустого аудиодвижка стирал восстановленную позицию. | Позиция сохраняется до Play и затем передаётся в seek. Перемотка до загрузки тоже сохраняется. Позднее восстановление не заменяет уже начатое воспроизведение. |
| Очередь останавливалась на недоступном следующем файле. | Next и естественное окончание пропускают недоступные следующие файлы; число попыток ограничено длиной очереди. Повтор очереди также проверяет следующие элементы. Autoplay исключает отсутствующие файлы. |
| Сохранение позиции проверяло файлы всей библиотеки и перезаписывало очередь; запросы накапливались. | Проверяются только ID снимка в SQLite, без обращений к файловой системе. Неизменившаяся очередь не переписывается. Пока запись выполняется, хранится один последний ожидающий снимок. |
| Завершение загрузки скрывало неудачу импорта. | Для файла показываются отдельный результат импорта и понятная причина ошибки. |
| Неудачный импорт не повторялся; отрицательный backend-кэш блокировал восстановление. | До трёх автоматических попыток для временных ошибок и ручной повтор. Backend повторно проверяет отрицательные результаты. Успешный импорт идемпотентен, пока трек существует в базе. |
| Поздний ответ опроса мог восстановить отменённую загрузку. | Отмена инвалидирует старый опрос: ответ не возвращает загрузку и не запускает импорт. |
| Поиск требовал целую строку в одном поле. | Все термины ищутся в объединённых названии, исполнителе, альбоме, исполнителе альбома и жанре с нормализацией Unicode, регистра и пробелов. |
| Источник F:\Music автоматически возвращался при пустом списке. | Приложение ожидает явного выбора папки пользователем. |
| Поздний запрос текста A изменял состояние трека B. | Ответ проверяется по поколению запроса и текущему треку. Автоматическое чтение не заменяет более новый ручной результат. Бейдж и кнопка используют только текст текущего трека. |
| Контекстное меню не позволяло снять лайк. | Добавление и удаление из любимых согласованы с кнопкой в строке. |
